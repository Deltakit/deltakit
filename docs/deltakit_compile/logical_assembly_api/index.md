# Logical Assembly API

The Logical Assembly API (`log_asm`) lets you build quantum error
correction experiments at the logical level — composing logical
operations such as memory experiments, lattice surgery, and stabilizer
gates without needing to specify the underlying physical circuit.

See the [guide](guides/index.md) to get started with a fundamental quantum memory experiment, or browse
[examples](examples/index.md) for standard QEC experiments.
